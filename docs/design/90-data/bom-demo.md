## 4. 損耗率の定義と計算

| 項目 | 定義 | 例 |
|---|---|---|
| `loss_rate` | 工程で失われる材料の割合（歩留り＝1−loss_rate） | 冲片 30%（打抜き・スロット抜き・耳切り） |
| `qty_net` | 親 1 単位に**正味**組み込まれる数量 | 定子冲片 10.8 KGM |
| `qty_gross` | 調達・払出に必要な数量＝`qty_net ÷ (1 − loss_rate)` | 10.8 ÷ 0.70 = 15.4286 KGM |
| BOM 展開 | 親の所要量 × 子の `qty_gross` を階層ごとに積上げ | §5 の算例 |
| 損耗の扱い | 材料費は `qty_gross` で原価算入。スクラップ売却は製造費用の控除（[09](../00-common/09-cross-domain-flow.md) の原価ルールに従う） | 【示例値】 |
