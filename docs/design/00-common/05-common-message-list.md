## 1. メッセージ採番・記述規則

| 項目 | 規則 |
|---|---|
| ID | `MSG-COM-{3桁}`（共通）、`MSG-{DOM}-{3桁}`（領域固有、各域 `93-messages.md`） |
| 種別 | `E`（エラー、処理中断）、`W`（警告、続行可）、`I`（情報・成功）、`C`（確認、利用者の選択が必要） |
| 本文 | 中国語。利用者視点で、**何が起きたか + どうすればよいか**を書く。技術用語・例外名・スタックトレースを含めない |
| プレースホルダ | `{0}`、`{1}`… の順序で埋める。例：`MSG-COM-014 必須項目「{0}」を入力してください` |
| 画面表示 | E = ダイアログ + 項目エラー、W = トースト（橙）/ダイアログ、I = トースト（緑）、C = 確認ダイアログ（OK/キャンセル） |
| API エラーコード | 各メッセージに対応する `code` を [03 API 共通规格](03-common-api-spec.md) 第 6 章の範囲で付与する |

## 3. 領域固有メッセージ

領域固有のメッセージは各域の `93-messages.md` に `MSG-{DOM}-{3桁}` で定義する。共通メッセージで表現できる場合は共通IDを使用し、重複定義しない。各域のメッセージ一覧は 20-matrix で集約する。
