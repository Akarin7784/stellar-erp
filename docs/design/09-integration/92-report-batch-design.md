## 1. 適用範囲

本設計書は INT 域の**帳票（PRT-INT-xxx）**と**バッチ（BAT-INT-xxx）**を定義する。外部 IF の詳細（項目・状態・エラー）は [02](02-tax-bank-interface.md)／[03](03-mes-wms-plm.md)／[04](04-openapi-file-notify.md) を正とし、本章では出力・実行条件・異常時の扱いを定義する。

**帳票の共通仕様**：PDF を既定（[画面共通规格 §14](../00-common/02-common-screen-spec.md)）。出力はサーバ側で生成し、出力履歴を `sys_print_log` に記録する。取引先名・金額は出力時点のスナップショットを用いる。

## 5. バッチ詳細

### 5.1 BAT-INT-001 接口失敗自動再送

| 項目 | 内容 |
|---|---|
| 実行方式 | 自動（1 分間隔） |
| 想定処理時間 | 1 分以内（100 件/回） |
| 対象 | `int_sync_task.status=40` かつ `next_retry_at ≤ now()` |
| 排他 | `FOR UPDATE SKIP LOCKED`。多重起動しない |
| 失敗時 | タスク単位で記録。バッチ自体は継続 |
| 関連機能 | F-INT-013 |

**処理手順**

1. 対象タスクを 100 件取得し、ロックする。
2. サーキットブレーカ・冪等キー・設定を検証する。
3. アダプタで送信し、成功なら `status=30`、失敗なら `retry_count+1`。
4. `retry_count ≥ 10` で `status=60`、E33 発行、アラート。
5. `int_retry_log`・`int_api_call_log` に記録する。

**異常処理**

| 異常 | 検知 | 処理 | 再実行 |
|---|---|---|---|
| サーキット OPEN | 設定 | 送信せず次回へ | 自動 |
| 相手先 5xx 継続 | 応答 | バックオフ延長 | 自動 |
| DB ロック競合 | 例外 | ロールバック、次回 | 自動 |
