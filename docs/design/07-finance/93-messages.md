## 1. 採番・記述規則

| 項目 | 規則 |
|---|---|
| ID | `MSG-FIN-001`～`MSG-FIN-133`（域内連番、廃止は欠番とせず「廃止」列で管理） |
| 種別 | `E`（エラー、処理中断）/ `W`（警告、続行可）/ `I`（情報・成功）/ `C`（確認） |
| 本文 | 中国語。利用者視点で「何が起きたか + どうすればよいか」。技術用語・スタックトレースを含めない |
| プレースホルダ | `{0}`、`{1}`… の順に埋める |
| 表示 | E=ダイアログ + 項目赤字、W=トースト（橙）、I=トースト（緑）、C=確認ダイアログ（[02 画面共通規格](../00-common/02-common-screen-spec.md) 第 13 章） |
| API エラーコード | [91-api-design.md](91-api-design.md) 第 3.3 節の対応表を正とする。共通コード（4001/4002/4003/4005 等）は [03 API 共通規格](../00-common/03-common-api-spec.md) 第 6 章 |
| 共通メッセージ優先 | 期間締切（MSG-COM-071）、必須漏れ（MSG-COM-040）、楽観排他（MSG-COM-033）等は共通 ID を使用し、本表に重複定義しない |
