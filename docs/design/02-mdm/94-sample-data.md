## 1. 適用範囲・データ区分

本文書は MDM 域の設計・実装・テストで使用するサンプルデータを定義する。数値・名称の区分は [README 第 8 章](../README.md) と [90-data/README.md](../90-data/README.md) に従う。

| 区分 | マーカー | 本域での例 |
|---|---|---|
| 実在データ | `【実データ】` | 国家標準番号（GB/T 2521.1-2016）、材料牌号（50W470、HT200、45#）、軸受型号（6205-2RS）、税制・税率、ISO 4217 通貨、UN/ECE Rec20 単位、CAS 会計科目、行政区画コード |
| 公開情報ベース | `【公開情報】` | 上場企業名（顧客・供應商の公開情報）、製品系列（YE3/YVF）、銀行名・行別コード |
| 仮定値 | `【示例値】` | 单价、安全在庫、信用限度、与信占用、評価点、倉庫面積、口座番号、聯行号（虚構） |

> 90-data のうち MDM が直接参照するファイル：`material-master.csv`、`material-category.csv`、`customer-master.csv`、`supplier-master.csv`、`demo-company.md`、`accounting-subjects.csv`、`approval-matrix.md`、`sources.md`、`code-lists/`（currency・uom・tax・**mdm-tax-code**・payment-terms・bank・region・country・warehouse-location・batch-number-rule・hs-code）。全件は各ファイルを正とする。90-data 実測（2026-10-20）：**24 ファイル／CSV 485 行／物料 54・科目 110・税碼 24・単位 21・分類 28／出典 109 項**。

### 3.5 90-data CSV の中文表記 → MDM 碼値 対応（取込時の変換規則）

`customer-master.csv`・`supplier-master.csv` は可読性のため中文表記を使用している。MDM へ取り込む際は次の対応で碼値化する（変換は `R__seed_mdm_*.sql` または取込スクリプトで実施）。

| CSV 列 | CSV 値の例 | MDM コード | 備考 |
|---|---|---|---|
| `customer_type` | 整机厂 | `10 企業` | 整机厂・終端ユーザーは企業として扱う |
| `customer_type` | （未使用） | `20 経銷商` / `30 個人` / `40 出口` | 必要時に拡張 |
| `status`（客户/供應商） | A | `1 有効`（`status=1`） | `A`=有効、`I`=使用停止（新規参照不可） |
| `customer_grade`（CSV なし） | — | `A/B/C/D` | `credit_limit_cny` と併せて与信審査で設定 |
| `supplier_type` | 生产厂家 | `10 製造商` | `20 経銷商`/`30 外注`/`40 服務` も同様に変換 |
| `cooperation_level` | 战略 / 合格 / 潜在 | `supplier_grade`（A/B/C）＋`admission_status`（30 合格 / 10 潜在） | 战略→A、合格→B、潜在→`admission_status=10`。暫定対応 |
| `material_type` | 成品 / 半成品 / 原材料 / 外购件 / 包装材料 / 低值易耗品 | `10 / 20 / 30 / 40 / 50 / 60` | [01](01-material-master.md) 2.5.1 対照表 |
| `credit_limit_cny` | 5000000 | `mdm_credit_limit.credit_limit_amount` = `5000000.00` | 通貨 CNY 固定 |

> **運用確定（Lead 承認 2026-10-20）**：`cooperation_level`（战略/合格/潜在）は CSV 上の「協力レベル」であり MDM の評価分级（A/B/C/D）とは概念が異なるため、取込時は `admission_status` への変換のみ行い（战略/合格→`30 合格`、潜在→`10 潜在`）、`supplier_grade` は月次評価（BAT-MDM-004）で設定する。本運用により未決事項は解消済み。
