### 3.2 多階 BOM（`BOM-3001000001-V01`）

- **構造**：4 階層・47 行（L1 21 行／L2 23 行／L3 3 行）。全行は [bom-demo.md](../90-data/bom-demo.md) §3 を正とする。
- **本域 DB へのマッピング**：

| 90-data の列 | `prd_bom_line` の列 | 変換 |
|---|---|---|
| `level`（0 成品／1 総成／2 部品・材料／3 素材） | `level_no`（相対深さ） | 設計上の深さは `level` と一致しない場合がある（例：定子冲片は 90-data では level 2、深さは 3）。`level_no` は展開時の深さ（成品=0）で自動計算する |
| `qty_net` | `component_qty` | そのまま（純使用量） |
| `loss_rate` | `loss_rate` | そのまま（比率） |
| `qty_gross` | `required_qty` | `qty_net ÷ (1 − loss_rate)`（4 桁四捨五入） |
| `source`（P/M/S） | `component_type`／`feeding_type` | P→10 标准件・先行払出、M→半成品（多階展開）、S→10 标准件 |
| `parent`／`child_code` | `material_id`／`component_material_id` | コードを ID に解決 |
| `uom` | `uom_code` | そのまま |

- **YE3 の 1 台あたり gross（主要品目）**：50W470 21.4286 KGM、QZY-2/180 2.6804 KGM、NMN 6640 0.4737 KGM、1032 浸漆 1.1579 KGM、機座铸件 7.2527 KGM、端盖铸件 4.5652 KGM、45# 1.7857 KGM、6205-2RS 2.0101 PCE（[bom-demo.md](../90-data/bom-demo.md) §5.1）。
- **120 PCE の展開算例**：毛要求量（概算）50W470 2,571.43 KGM／厳密展開 2,623.55 KGM（本設計の MRP は厳密展開、[05](05-mrp-planning.md) 4.4 注記）。
