## 1. 採番規則

| 項目 | 規則 |
|---|---|
| ID | `MSG-SAL-{3桁}`。域內連番。ブロック単位で機能に割当てる（§2） |
| 種別 | `E`（エラー・処理中斷）、`W`（警告・続行可）、`I`（情報・成功）、`C`（確認） |
| 本文 | 中國語。**何が起きたか + どうすればよいか**を利用者視點で記述。技術用語・內部例外名・スタックトレースを含めない |
| プレースホルダ | `{0}`、`{1}`… の順。金額・數量は桁區切り・通貨/単位付きで表示する |
| API 連携 | 各メッセージに対応する業務コードを [91-api-design.md §5](91-api-design.md) に定義。HTTP ステータスは共通規格に従う |
| 表示 | E = ダイアログ + 項目赤字、W = トースト（橙）/ダイアログ、I = トースト（緑）、C = 確認ダイアログ |
| 共通優先 | 共通メッセージ（`MSG-COM-xxx`）で表現できる場合は共通 ID を使用し、本一覧に重複定義しない（§3） |
| 欠番 | 機能追加用に予約。再利用は禁止（採番の安定性を優先） |
