## 1. 適用範囲・使い方

本文件は全業務域が共通で使用する**コード体系とコード値**を定義する。

- 各域設計書は本表のコード値をそのまま使用し、独自のコード値・名称を定義しない（域固有コードは各域 `00-overview.md` に定義）。
- 実データの詳細（全件 CSV、出典 URL、参照日）は [90-data/](../90-data/) 配下の CSV と [90-data/sources.md](../90-data/sources.md) を正とする。本文件は設計書から参照するための要約である。
- 本文件で `【実データ】` を付したものは実在の標準・法令・公開情報に基づく。`【設計値】` は本システムの内部設計値、`【要確認】` は data-researcher の検証待ちである。
- 本文件のコード値を変更する場合は、影響する全設計書を grep して更新する（Lead 承認必須）。

## 2. コード体系の方針

| 分類 | 例 | 管理場所 | 備考 |
|---|---|---|---|
| 国際標準コード | 通貨（CNY）、国（CN）、単位（KGM） | `mdm_currency` / `mdm_country` / `mdm_uom` | 標準コードをそのまま採用 |
| 中国国内標準コード | 行政区划（3204 常州）、会计科目（1122）、HS 编码 | 各マスタ | 標準コードをそのまま採用 |
| 業務マスタコード | 物料、客户、供应商、仓库、库位、工作中心 | 各マスタ（採番規則は 08 第 2 章） | 社内設計値 |
| 固定区分値 | ステータス、取引種別、税区分 | 本ファイル / 08 / 各域 | Java enum + SMALLINT |
| 外部システムコード | 银行联行号、客户订单号、发票号码 | 業務データ / マスタ | 外部採番を保存 |
