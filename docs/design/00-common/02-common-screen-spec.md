## 1. 適用範囲

全画面（Web UI）に適用する。個別画面の設計書は本規格を前提とし、逸脱する場合は理由を明記する。フロントエンドは Vue 3 + TypeScript + Element Plus（[ADR-0004](../../adr/0004-frontend-stack.md)）。

## 2. 画面類型

| 類型 | コード | 構成 | 例 | 共通仕様 |
|---|---|---|---|---|
| 一覧検索 | LIST | 検索条件 + 一覧 + ページング | 受注一覧、在庫照会 | 第 4 章 |
| 登録編集 | EDIT | ヘッダ + 明細 + 操作ボタン | 受注登録、発注入力 | 第 5 章 |
| 参照詳細 | VIEW | ヘッダ + 明細 + 履歴/関連 | 受注詳細、工単詳細 | 第 6 章 |

## 3. 共通レイアウト

### 3.1 画面区域

| 区域 | 内容 | 高さ/配置 |
|---|---|---|
| グローバルヘッダ | ロゴ、会社/工場切替、通知、ユーザメニュー（個人中心/ログアウト） | 固定 56px |
| サイドメニュー | 権限に応じたメニューツリー（2 階層まで表示、3 階層以降は展開） | 固定 220px（折畳可） |
| パンくず + タイトル | 現在位置、画面名、状態バッジ | 固定 40px |
| メイン領域 | 検索条件 / ツールバー / 一覧・明細 / フッタ | スクロール |
| フッタ | ページング、合計、最終更新日時 | 固定 40px（一覧のみ） |

### 3.2 共通表示要素

- 画面タイトルはメニュー名と一致させる。タブで複数画面を開く場合も同一。
- 状態バッジは [01 共通项目定义](01-common-item-definitions.md) 14.3 の色規則に従う。
- 金額・数量・日付の表示形式は 01 共通项目定义 第 6 章に従う。
- ローディング中は対象領域にスピナー + 操作ボタン無効化。3 秒以内に応答がない場合は「処理中…」表示。
- エラー時は画面上部にエラーサマリ（件数 + 一覧）、項目単位は項目直下に赤字。

## 4. 一覧検索画面の共通仕様

### 4.1 検索条件

| 項目 | 仕様 |
|---|---|
| 配置 | 画面上部。折畳可能（既定は展開）。条件が多い場合は「詳細条件」トグル |
| 実行 | 「検索」ボタン / Enter。検索中はボタン無効化 |
| クリア | 「クリア」で既定値に戻す（自動検索はしない） |
| 既定条件 | 機能ごとに定義（例：当月、未完了、自部門）。初期表示時に適用 |
| 復元 | 画面離脱→戻り時は直前の検索条件・ページ・ソートを復元（sessionStorage）。ログアウトで破棄 |
| コード選択 | マスタから取得。初期表示は有効データのみ。削除済み・無効コードは検索条件で選択不可 |
| 日付範囲 | 両端含む。開始 > 終了はエラー `MSG-COM-002` |
| ブランク | 未入力条件は検索条件に含めない（全件対象） |

### 4.2 一覧表示

| 項目 | 仕様 |
|---|---|
| 既定ソート | 登録日時降順（機能で定義がある場合はそれに従う） |
| ソート | 列ヘッダクリックで昇順/降順/解除。複数キー可（Shift+クリック） |
| ページング | 20/50/100/200（既定 20）。総件数・現在ページ表示。100,000 件超は「条件を絞ってください」 |
| 列幅 | ドラッグ変更可。表示/非表示・順序をユーザ単位で保存（`sys_user_preference`） |
| 固定列 | チェックボックス列、主要コード列を左固定。操作列を右固定 |
| 行選択 | 単一選択（ラジオ）/複数選択（チェックボックス）。一括操作時のみ複数 |
| 行操作 | ダブルクリック or 行内「詳細」リンクで参照詳細へ。行内ボタンは最大 3 個 + 「その他」メニュー |
| 空データ | 「該当するデータがありません」を表示（テーブルヘッダは残す） |
| 総件数 | 表示（`total`）。件数取得が重い場合は近似値を許容し「約 n 件」と表示（機能で定義） |

### 4.3 一括操作

| 操作 | 仕様 |
|---|---|
| 対象 | 選択行 or 検索条件に一致する全件（「全件選択」リンク）。後者の場合、最大件数（例 1,000 件）を超えたらエラー |
| 実行前確認 | 対象件数・操作内容をダイアログで明示。「実行」で開始 |
| 結果 | 成功件数・失敗件数・失敗理由一覧を表示。失敗行は一覧でハイライト |
| 排他 | 各行の version を検証。1 件でも競合したら全体ロールバック（設定で部分成功可、機能で定義） |
| 権限 | 一括操作ごとに権限コードを定義。権限なし項目は非表示 |

### 4.4 エクスポート

| 項目 | 仕様 |
|---|---|
| 形式 | Excel（.xlsx）。CSV はデータ連携用途のみ |
| 対象 | 選択行 or 検索条件全件。1 回 10,000 件まで。超過時は非同期ジョブ（進捗通知 + ダウンロード画面） |
| 内容 | 一覧に表示中の列 + 機能定義の追加列。個人情報はマスキング |
| 権限 | `{module}:{resource}:export`。エクスポート操作を監査ログに記録 |
| ファイル名 | `{機能名}_{yyyyMMddHHmmss}.xlsx` |

## 5. 登録編集画面の共通仕様

### 5.1 モード

| モード | 遷移 | 編集可否 | 保存ボタン |
|---|---|---|---|
| 新規 | 一覧「新規」 | 全項目編集可 | 「保存」「保存して継続」「キャンセル」 |
| 編集 | 一覧/詳細「編集」 | ステータス・権限に応じ制御 | 同上 |
| 参照 | 一覧行選択 | 全て参照のみ | 「編集」「戻る」 |
| 複製 | 詳細「複製」 | 業務キーのみ変更可、他はコピー | 「保存」 |
| 承認待ち | 提出後 | 原則参照のみ（差戻しで編集可） | 承認操作のみ |

### 5.2 入力・保存の共通動作

| 項目 | 仕様 |
|---|---|
| 初期値 | 新規時：日付=当日、会社/工場=ログインユーザの既定、通貨=CNY、数量=0、税率=マスタ既定 |
| コード入力 | コード直接入力 + 選択ダイアログ。フォーカスアウトで存在チェック・名称表示 |
| 自動計算 | 数量・単価変更時に金額・税額・合計を再計算（項目定義の計算順序） |
| 明細行 | 「追加」で末尾に行追加（行番号自動）「挿入」は選択行の上「削除」は確認後「コピー」は選択行を複製。最低 1 行（0 行保存不可）。最大 1,000 行 |
| 行移動 | ドラッグ or 上下ボタン。行番号は保存時に 10 刻みで振り直し |
| 保存 | 二重送信防止（ボタン無効化 + Idempotency-Key）。成功時トースト「保存しました」 |
| 連続登録 | 「保存して継続」はヘッダ一部項目と明細をクリアし、連続採番 |
| 戻る/キャンセル | 未保存変更がある場合は確認ダイアログ「変更を破棄しますか？」 |
| 楽観排他 | 編集開始時の version を保存時に送信。競合時 `MSG-COM-005` + 「最新情報を再取得」ボタン |
| 権限なし項目 | 非表示（DOM に出さない）。API も返さない |
| 入力エラー | 最初のエラー項目へ自動フォーカス。エラーサマリに「n 件のエラー」 |
| 自動保存 | 明示保存に加え、第一版で下書き自動保存を対応（TODO：保存間隔・下書き保管先の設計が未作成） |

### 5.3 承認操作ボタン（WF 連携画面）

| ボタン | 表示条件 | 動作 |
|---|---|---|
| 提出 | ステータス=草稿 かつ 提出権限 | 保存後、ワークフローへ提交。成功でステータス=承認待ち |
| 承認 | 承認待ち かつ 承認者 | 承認コメント（任意）を入力し承認。最終承認で承認済 |
| 却下 | 承認待ち かつ 承認者 | 却下理由必須。ステータス=却下 |
| 差戻し | 承認待ち かつ 承認者 | 差戻し先・理由必須。ステータス=草稿 |
| 撤回 | 承認待ち かつ 申請者 | 承認者が未処理の場合のみ可。ステータス=草稿 |
| 取消 | 承認済/発行済 かつ 権限 | 後続処理がない場合のみ可。関連在庫・会計の逆処理を伴う |

## 6. 参照詳細画面の共通仕様

- ヘッダ情報、明細、承認履歴（承認者・日時・コメント・結果）、変更履歴（項目・変更前後・変更者）、関連伝票（リンク）、添付ファイル、コメントをタブまたはセクションで表示。
- 関連伝票リンクは権限に応じ表示。遷移先が参照不可の場合はリンクを出さない。
- 帳票出力ボタン（権限がある場合）。

## 7. 選択ダイアログの共通仕様

| 項目 | 仕様 |
|---|---|
| 起動 | コード項目の参照ボタン、または明細行の「選択」 |
| 検索 | ダイアログ内で検索条件を指定。初期表示は有効データ先頭 20 件 |
| 選択 | 単一/複数。ダブルクリックで確定 |
| 返却 | 呼出元の定義項目のみ返す（全項目を返さない） |
| 制約 | 無効・削除済みは選択不可。特定条件（例：与信停止顧客）は選択時に警告 |
| 新規登録 | マスタ登録権限がある場合のみ「新規登録」ボタン（別タブ/モーダル） |

## 8. ワークフロー画面の共通仕様

| 画面 | 内容 |
|---|---|
| 待办一覧 | 自分の承認待ちタスク。申請者・申請日・金額・経過日数・緊急度でソート。エスカレーション表示 |
| 承認画面 | 申請内容（参照）+ 承認経路図 + 承認/却下/差戻し/加算・転送 + コメント。添付参照可 |
| 已办一覧 | 自分が処理したタスク。結果・日時・コメント |
| 我发起的 | 自分の申請。進捗・現在承認者・撤回可否 |
| 抄送我的 | 参照通知。既読管理 |
| 审批历史 | 承認経路のタイムライン（誰が・いつ・何を・コメント） |

- 承認画面では業務項目の**項目レベル編集権限**（WF 設計書のフィールド権限）に従い、編集可/参照のみ/非表示を制御する。
- 承認・却下後は待办一覧へ戻り、成功トーストを表示。

## 9. ダッシュボードの共通仕様

- KPI カード（指標名・値・前期比・目標比）、グラフ（ECharts）、ドリルダウン（クリックで一覧へ遷移、条件引継ぎ）。
- データ更新時刻を表示。キャッシュ利用時は「最終更新」を明示。
- 権限に応じカードを出し分け。データ範囲（部門/全社）を適用。
- 初期表示は 3 秒以内（集計テーブル/キャッシュ利用）。

## 10. ウィザードの共通仕様

- ステップ表示（現在位置・全ステップ）。前へ/次へ/キャンセル。
- 各ステップで入力チェック。エラーがある限り次へ進めない。
- 最終確認ステップで入力内容を要約表示し「実行」。
- 実行中は進捗表示。中断不可（実行後の取消は業務操作として別途）。
- 離脱時は確認ダイアログ。実行結果（成功/失敗件数・エラー一覧）を表示。

## 11. 画面項目定義・イベント定義の記述形式

個別画面は [画面定義書テンプレート](../_template/02-screen-definition-template.md) を使用する。最低限、以下を必ず記載する。

1. 画面項目定義（No / 項目 ID / 項目名 / 区分 / 種別 / 型・桁 / 必須 / 初期値 / 入力チェック / データソース / DB 項目 / 権限 / 備考）
2. イベント処理（イベント / トリガ / 処理内容 / 呼出 API / 画面遷移 / エラー時）
3. 表示制御（条件 / 対象 / 制御内容）
4. 検索条件仕様・一覧仕様（一覧画面）
5. メッセージ一覧（画面で表示する全メッセージ）

## 12. 権限制御

| 層 | 制御 | 実装 |
|---|---|---|
| 画面 | メニュー表示/非表示、直接 URL アクセス時の 403 | ルートガード + 権限コード |
| 操作 | ボタン表示/非表示、API 実行時の権限チェック | `@SaCheckPermission` + フロント `v-permission` |
| 項目 | 項目の表示/非表示、編集可/参照のみ | 項目権限定義（画面 ID + 項目 ID + ロール） |
| データ | 検索結果の行レベル絞込 | MyBatis-Plus データ権限インターセプタ |
| 帳票/エクスポート | 出力可否、マスキング | 権限コード + マスキング処理 |

- フロントの制御は UX のためであり、**API 側で必ず再チェック**する（二重防御）。
- 権限なしで直接 URL を開いた場合は 403 画面を表示し、メニューへ戻る導線を出す。

## 13. メッセージ表示規則

| 種別 | 表示 | 継続時間 | 例 |
|---|---|---|---|
| 成功（I） | トースト（右上、緑） | 3 秒 | 「保存しました」 |
| 情報（I） | トースト/通知領域 | 3 秒 | 「承認経路を送信しました」 |
| 警告（W） | トースト（橙）+ 必要時ダイアログ | 5 秒 | 「在庫が不足しています。不足分は発注残として扱います」 |
| エラー（E） | ダイアログ（モーダル）+ 項目赤字 | 手動で閉じる | 「与信限度を超過しています」 |
| 確認 | ダイアログ（OK/キャンセル） | 手動 | 「取消しますか？関連する在庫・会計処理も戻します」 |

- メッセージ本文はユーザ向けに分かりやすく（技術用語・スタックトレースを出さない）。詳細（エラーコード）は折畳み内に表示。
- 連続する同一エラーは重複表示しない。

## 14. 帳票・エクスポート

- 帳票は PDF（サーバ生成）を既定。ブラウザの印刷機能は使用しない（レイアウト保証）。
- 帳票プレビュー画面で拡大/縮小/ページ移動/ダウンロード/印刷（PDF を開く）を提供。
- 出力履歴（誰がいつ何を出力したか）を記録。再出力可。
- 帳票項目・レイアウトは `92-report-batch-design.md` で定義。

## 15. セッション・セキュリティ（画面側）

| 項目 | 仕様 |
|---|---|
| セッションタイムアウト | 8 時間（`sa-token.timeout`）。残り 5 分で警告、失効時はログイン画面へ |
| 多重ログイン | 同一ユーザの同時ログイン可（設定で 1 端末に制限可）。強制ログアウト時は通知 |
| CSRF | トークンヘッダ方式（Authorization）。Cookie 認証は使用しない |
| XSS | ユーザ入力はエスケープ表示。HTML 入力項目は定義しない |
| 機密情報 | パスワード・口座番号等は画面に残さない。コピー禁止項目は右クリック/選択禁止 |
| 操作ログ | 主要操作（登録/更新/削除/承認/出力/印刷）はサーバ側で記録。画面側は送信しない |
| エラー画面 | 403 / 404 / 500 の専用画面。500 は問い合わせ用の `trace_id` を表示 |

## 16. アクセシビリティ・操作性

- 色のみで状態を伝えない（アイコン・テキスト併用）。コントラスト比 4.5:1 以上。
- 全操作がキーボードで可能（Tab 移動、Enter 確定、Esc 閉じる）。フォーカス順は論理順。
- テーブルは行数が多い場合もスクロールで操作可能。固定ヘッダ。
- 日付・コード入力は手入力と選択の両方を許容。IME 入力中の Enter は確定に使わない。
- 画面幅 1280px 以上を推奨。1024px 未満は横スクロールを許容（レイアウト崩れは不可）。
