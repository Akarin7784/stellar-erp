## 1. 採番・記述規則

| 項目 | 規則 |
|---|---|
| ID | `MSG-PUR-{3桁}`（本域固有）。共通メッセージは `MSG-COM-xxx` を使用し、重複定義しない |
| 種別 | `E`（エラー、処理中断）/ `W`（警告、続行可）/ `I`（情報・成功）/ `C`（確認、利用者の選択が必要） |
| 本文 | 中国語。利用者視点で「何が起きたか + どうすればよいか」を記述。技術用語・例外名・スタックトレースを含めない |
| プレースホルダ | `{0}`、`{1}`… の順に埋める。数値は桁区切りを付けない（画面側で整形） |
| 画面表示 | E = ダイアログ + 項目エラー（02 §13）、W = トースト（橙）/ダイアログ、I = トースト（緑）、C = 確認ダイアログ |
| API 対応 | 各メッセージには [91-api-design.md](91-api-design.md) §6 で `code`（40000～49999）を付与する |
| 定義場所 | 各機能文書の「エラー処理・メッセージ」章。本一覧が**全体の正**（重複・欠番を許容するが、同一 ID の意味変更は禁止） |
| 採番区間 | 001～026 请购 / 030～047 询价 / 048～067 订单 / 068～086 收货・IQC / 087～099 退货 / 100～116 发票・应付 / 117～125 跟踪・绩效 / 126 汎用 |

> メッセージ数：113 件（`MSG-PUR-001`～`MSG-PUR-126` のうち欠番を除く）。`MSG-COM-xxx` は共通メッセージ（利用頻度の高いものは §2）。

## 2. 共通メッセージの利用方針

以下の共通メッセージは本域でも使用する（本文・対処は [05-common-message-list.md](../00-common/05-common-message-list.md) を正とする）。

| メッセージ ID | 用途（本域） |
|---|---|
| `MSG-COM-004` | 非同期エクスポート受付（帳票出力） |
| `MSG-COM-030` / `MSG-COM-031` | 操作権限なし / データ参照権限なし |
| `MSG-COM-032` | 対象データ不存在・削除済み |
| `MSG-COM-033` | 楽観排他競合（version 不一致） |
| `MSG-COM-034` | 状態不整合（現在状態で操作不可） |
| `MSG-COM-035` | 行ロック・同時処理 |
| `MSG-COM-040` / `MSG-COM-041` | 必須漏れ / 桁数超過 |
| `MSG-COM-045` / `MSG-COM-046` | 相関チェック（数量・日付） |
| `MSG-COM-047` / `MSG-COM-048` | 数量 > 0 / 金額非負 |
| `MSG-COM-049` / `MSG-COM-050` | コード不存在 / 一意制約違反 |
| `MSG-COM-051` | 合計不一致（警告） |
| `MSG-COM-070` | 在庫不足 |
| `MSG-COM-071` | 会計期間締切済 |
| `MSG-COM-072` | 下流処理ありで取消不可 |
| `MSG-COM-073` | 承認経路未設定 |
| `MSG-COM-080` / `MSG-COM-081` / `MSG-COM-082` | システムエラー / 通信エラー / レート制限 |
| `MSG-COM-084` / `MSG-COM-085` | 処理中 / データ取得失敗 |

## 4. API エラーコードとの対応

| 範囲 | 用途 |
|---|---|
| `40000～49999` | 采购域の業務エラーコード。詳細対応（code ↔ MSG）は [91-api-design.md](91-api-design.md) §6 を正とする |
| `40004/40005/40022/40039/40044/40046/40072/40074/40076/40081` | 200 応答の `data.warnings[].code`（処理継続の警告） |
| `40099` | 分類不能な業務エラー（`MSG-PUR-126`） |
| `4001～4005` | 共通業務コード（不存在・状態不整合・排他・期間締切・二重処理） |
| `5000/5001` | システムエラー・メンテナンス（共通） |

> エラーコードとメッセージ本文は 1 対 1 を基本とするが、同一メッセージを複数の操作で使用する場合は同じコードを共用してよい（例：`MSG-PUR-003` は登録・転単・PO 生成で共用）。

## 5. メッセージ表示規則（本域固有の補足）

| # | 規則 |
|---|---|
| 1 | 金額・数量を含むメッセージは、通貨コード（CNY）・単位コード（KGM/PCE 等）を本文に含める（例「可收上限（29,400.0000 KGM）」） |
| 2 | 差異・滞留・期限に関する警告は、対象伝票番号（PO/GR/PIV）を本文またはリンクで示す |
| 3 | 同一操作で複数の警告が発生する場合は、エラー（E）を優先表示し、警告（W）は一覧表示する |
| 4 | 承認・支払・会計計上などの不可逆操作は確認（C）を必ず挟み、影響範囲（在庫・暫估・買挂）を明示する |
| 5 | 権限不足（3001/3002）・期間締切（4004）・排他（4003）は API でも同一メッセージを返し、画面と本文を一致させる |
