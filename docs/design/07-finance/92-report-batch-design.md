## 1. 適用範囲

本域の帳票（法定帳簿・法定报表・業務帳票）、定期バッチ、外部インタフェース（銀企・数电票・電子税務局）を定義する。帳票は PDF（サーバ生成）を既定とし、一覧系は Excel 出力も可。出力は監査ログに記録し、再出力可能とする。帳票 ID は `PRT-FIN-xxx`、バッチは `BAT-FIN-xxx`、外部 IF は `IF-FIN-xxx`。

- 出数公式は `fin_statement_formula`（`statement_type=SCE`）に保持。期末合計が BS 行 69（所有者权益合计）と一致することを検証する。法定様式（財会〔2019〕6 号）の完全版（その他包括收益内訳・株主別変動）は 実装順 P2（[00-overview](00-overview.md) 未決 #3）。

## 5. 主要バッチ詳細

### 5.1 BAT-FIN-004 自动凭证事件消费

| 項目 | 内容 |
|---|---|
| 実行方式 | 分次（10 秒間隔）、多重起動防止（`pg_advisory_lock('FIN_AUTO_VOUCHER')`） |
| 対象 | `sys_outbox_event`（status=NEW/FAILED、event_type が FIN 購読対象） |
| 処理手順 | ① 未処理イベント 100 件取得 → ② `fin_auto_voucher_log` に幂等登録 → ③ テンプレート選択 → ④ 金額評価・科目解決 → ⑤ 凭证 INSERT（10 草稿）→ ⑥ auto_post 設定時は自動审核/記帳 → ⑦ ログ status=2、outbox=PUBLISHED |
| 更新対象 | `fin_auto_voucher_log`、`fin_voucher`、`fin_voucher_line`、`fin_account_balance`（auto_post 時）、`sys_outbox_event` |
| 異常処理 | テンプレート無/貸借不一致/税種マップ無 → status=3、リトライ（1/5/30/120/360 分、最大 10 回）→ status=9 + アラート（MSG-FIN-103） |
| 冪等 | `event_id` UNIQUE + `(source_type, source_id)` UNIQUE。再実行は成功ログをスキップ |
| 監視 | 未処理件数を画面（SCR-FIN-042）と Actuator メトリクスで可視化。月結チェック項目 1 |

### 5.2 BAT-FIN-002/003 暂估入账・冲回

| 項目 | 内容 |
|---|---|
| 起動条件 | 期間 OPEN、在庫月結前（002）/ 在庫月結後または発票到達（003） |
| 対象（002） | E14 受信済で `fin_payable`（accrual_flag=true、reversed_flag=false）が未作成の収貨、または未請求の収貨 |
| 対象（003） | `fin_payable`（accrual_flag=true、reversed_flag=false）で、対応発票が到達したもの・月初の一括冲回対象 |
| 処理手順（002） | ① 収貨明細取得 → ② 税抜額計算 → ③ AP（暫估）INSERT → ④ J01 生成（TPL-FIN-J01）→ ⑤ 監査ログ |
| 処理手順（003） | ① 対象暫估取得 → ② J02（赤伝/反向）生成 → ③ `reversed_flag=true` → ④ 監査ログ |
| 冪等 | `(source_type, source_id)` UNIQUE + `reversed_flag`。再実行で二重冲回しない |
| 異常 | 在庫月結未了（002 は月結前のみ）、期間 CLOSED → 中断 + アラート |

| 起動条件 | 在庫月結済み（E20）、E22/E23/E24 処理済み、BAT-FIN-010 完了 |
| 処理手順 | ① 工单別に材料（E22）・人工（E23）・製造費用（allocation）を帰集 → ② 品種法：約当産量→完工総成本・単位成本／分批法：工单別完工成本 → ③ `fin_wip_balance`・`fin_product_cost` 保存 → ④ 差異分析（標準原価あり）→ ⑤ 確認操作で J16 生成・記帳 |
| 冪等 | `(period_code, cost_object_type, cost_object_id)` UNIQUE。再計算は確認取消後に上書き |
| 異常 | 負在庫/無報工/無 BOM は異常一覧（MSG-FIN-112）、5001≠WIP はエラー（MSG-FIN-113） |

### 5.6 BAT-FIN-012 损益结转

| 項目 | 内容 |
|---|---|
| 起動条件 | BAT-FIN-009 全 OK、月結向导から実行、期間 OPEN、未転記 |
| 処理手順 | ① 収益類（6001/6051/6111/6301 等）当期貸方発生を集計 → ② 費用類（6401/6402/6403/6601/6602/6603/6701/6711/6801 等）当期借方発生を集計 → ③ J28（収益→4103）/J29（4103→費用）生成 → ④ 自動記帳 → ⑤ 損益科目残高 0 検証 → ⑥ `is_closing=true` |
| 冪等 | 期間×1 回。既存転記凭证があればスキップ（MSG-FIN-127） |
| 異常 | 残高 ≠0 → 転記取消（赤伝）してエラー（MSG-FIN-126） |

### 5.7 BAT-FIN-013 年度结转

| 項目 | 内容 |
|---|---|
| 起動条件 | 12 月 CLOSED、年結チェック合格、財務総監権限 |
| 処理手順 | ① 4103 残高確定 → ② J30（4103→4104）→ ③ 法定盈余公积（10%）計上 → ④ 翌年 12 期間作成・1 月 OPEN → ⑤ 期首残高繰越（資産/負債/権益）→ ⑥ 前年度 YEAR_CLOSED |
| 冪等 | 年度×1 回。失敗時はロールバックして再実行可 |
| 異常 | 12 月未 CLOSED / 未記帳凭证 / 損益転記未了 → 中断（MSG-FIN-125） |

### 5.8 BAT-FIN-015/016 申報辅助・税金计提

| バッチ | 処理手順 | 冪等 | 異常 |
|---|---|---|---|
| BAT-FIN-015 | ① 销项（`fin_invoice` OUTPUT＋2221.01 調整）集計 → ② 進項（INPUT 已勾选＋2221.01）→ ③ 転出（2221.01）→ ④ 上期留抵 → ⑤ 応納税額・期末留抵・附加税計算 → ⑥ `fin_vat_return` UPSERT（40） | 期間 UNIQUE、再生成可 | 期間 CLOSED 時は読取のみ、差異は警告（MSG-FIN-085） |

### 6.2 IF-FIN-001 银行对账单导入（受信）項目

| No | 項目 | 型/桁 | 必須 | 説明 | 備考 |
|---|---|---|---|---|---|

| 2 | 摘要 | VARCHAR(500) | △ | 銀行摘要 | — |
| 3 | 对方户名 | VARCHAR(200) | △ | 入出金相手 | マッチングに使用 |
| 4 | 对方账号 | VARCHAR(64) | △ | マスク保存 | — |
| 5 | 收入金額 | NUMERIC(18,2) | △ | 入金 | 収支いずれか必須 |
| 6 | 支出金額 | NUMERIC(18,2) | △ | 出金 | 同上 |
| 7 | 余额 | NUMERIC(18,2) | △ | 取引後残高 | — |

| 4 | 金額 | NUMERIC(18,2) | ○ | CNY |

### 6.4 IF-FIN-004/005 数电票・進項查验

| 項目 | 内容 |
|---|---|
| IF-FIN-004 | 销项发票発行：`fin_invoice`（OUTPUT）→ INT → 数电票平台。返却の发票号码・PDF を `fin_invoice` に反映。失敗は SAL/E12 側へエラー通知 |
| IF-FIN-005 | 進項发票查验/勾选：`fin_invoice`（INPUT）の `invoice_code/invoice_no/amount/tax_amount` を送信し、検証結果（一致/不一致）と勾选状態を `verify_status/verify_date` に反映 |
| 冪等 | 发票番号 + 種別で一意。再送は同一結果を返す |
| 異常 | 不一致は `verify_status=3`、経理が手動確認。通信失敗はリトライ + アラート |

### 6.5 IF-FIN-006 增值税申报数据导出

- `fin_vat_return`（status=50 已確認）から申報表形式（XML/Excel）を生成し、電子税務局へ提出（実装順 P2 は INT が直連、P0 実装時点 はファイル出力・手動アップロード）。
- 出力ファイルの SHA256 と出力者・日時を監査ログに記録。
- 申告後の修正は「更正申告」として新規版の `fin_vat_return` を作成する（既存は保持）。
