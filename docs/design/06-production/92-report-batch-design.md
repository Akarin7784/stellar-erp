## 2. 帳票詳細

### 2.1 PRT-PRD-001 工单（制造指示书）

| 項目 | 内容 |
|---|---|
| 目的 | 現場に製造指示を発行する。材料・工序・数量・日程・検査点を明記 |
| 出力条件 | `order_status ∈ {30,35}`。下达時に自動出力（設定 `print.on.release=true`） |

## 4. バッチ詳細

### 4.1 BAT-PRD-001 MRP 自動実行

| 項目 | 内容 |
|---|---|
| 実行方式 | 日次（`cron: 0 0 20 * * ?`）＋手動（SCR-PRD-021） |
| 対象 | 全工場（設定 `mrp.auto.factory=ALL`） |
| 前提 | 会計期間が締切でない、低层码が最新（必要なら BAT-PRD-002 を同期実行） |
| 処理手順 | ① ロック取得 → ② 計画対象抽出 → ③ 需要収集 → ④ 净需求・計画订单・動作消息（[05](05-mrp-planning.md) 3.3） → ⑤ 結果保存・通知 → ⑥ ロック解放 |
| 出力 | `prd_mrp_run`・`prd_mrp_demand`・`prd_mrp_plan_order`・`prd_mrp_action` |
| 異常時 | 品目単位のエラーはスキップして継続し、`error_count` に記録。全体エラーは `run_status=90`、運用にメール通知 |
| 再実行 | 可（新 `mrp_run_no`）。前回の未確認計画订单は残す（BR-MRP-13） |
| 監視 | 実行時間・件数・エラー数を `prd_mrp_run` に記録。5 分超で警告 |

### 4.2 BAT-PRD-002 低层码再計算

| 項目 | 内容 |
|---|---|
| 契機 | BOM 承認/廃止イベント（非同期）、日次、MRP 実行前の未更新検出 |
| 処理 | 全有効 BOM から親子エッジを構築 → トポロジカル順で最大深さを伝播 → `prd_material_planning.low_level_code` を一括更新（[01](01-bom-routing-workcenter.md) 4.4） |
| 異常時 | 循環検出で中断し `MSG-PRD-010`、BOM 担当者へ通知 |
| 冪等 | 何度実行しても同じ結果（決定的） |

### 4.3 BAT-PRD-003 安全在庫・発注点チェック

| 項目 | 内容 |
|---|---|
| 処理 | INV の利用可能在庫と `prd_material_planning.safety_stock_qty`／`reorder_point_qty` を比較し、割れ品目を抽出。設定により `prd_demand_forecast`（`forecast_type=30`）へ需要登録、または通知のみ |
| 出力 | 通知（計画員）、`prd_mrp_demand`（次回 MRP の需要源） |
| 冪等 | 当日分の重複登録を除外 |

### 4.4 BAT-PRD-004 納期遅延・滞留アラート

| 項目 | 内容 |
|---|---|
| 処理 | ① `planned_end_date < 当日` で未完の工单 ② 前工程完了後 1 日以上投入されていない工序 ③ `is_hold` の工单 ④ 納期超過の委外訂单 を抽出 |
| 出力 | 通知（生産経理・計画員・車間主管）、看板のリスト（SCR-PRD-030） |
| 冪等 | 当日分は 1 回のみ通知（`sys_notification` の重複排除） |

### 4.5 BAT-PRD-005 工单自動結案

| 項目 | 内容 |
|---|---|
| 処理 | BR-WO-09 の全条件（全数入庫・全数報工・検査完了・原価確定・未領 0）を満たす `order_status=40` の工单を `45` に更新 |
| 設定 | `wo.auto_close.enabled=true`（既定）。無効時は手動結案のみ |
| 出力 | 結案ログ、`prd_work_order.closed_*` |
| 異常時 | 条件未達はスキップ（エラーにしない）。原価未確定は翌日再判定 |

### 4.6 BAT-PRD-006 在制品・工单成本结转

| 項目 | 内容 |
|---|---|
| 実行 | 月末翌 1 日 02:00（FIN 月結前） |
| 処理 | ① 工单別の実績材料費・人工費・製造費用を集計 ② 完工数量按分で完工原価と在制品を計算（[03](03-material-issue-reporting.md) 4.7） ③ `prd_work_order.actual_total_cost`／`wip_cost`／`cost_status=10` を更新 ④ FIN へ配賦結果を連携（J15/J16 の基礎） |
| 冪等 | 当期間内の再実行は上書き |
| 異常時 | 領料/報工の未確定がある工单はスキップし、一覧を通知 |

|---|---|
| 目的 | MES へ工单・工序を下发し、MES の実績（良品・不良・工数）を本域へ回传する |
| 認証 | API Key＋HMAC（第一版）／OAuth2。[03](../00-common/03-common-api-spec.md) 14 章に準拠 |
| タイムアウト・リトライ | 10 秒、3 回、指数バックオフ |
| 冪等キー | 下发：`workOrderNo + operationSeq`／回传：`workOrderNo + operationSeq + reportAt` |
| 頻度 | リアルタイム（下发は下达時、回传は作業完了時） |

**下发項目（PRD → MES）**

| No | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| 1 | workOrderNo | string | ○ | 工单番号 |
| 2 | materialCode | string | ○ | 品目コード |
| 3 | orderQty | string | ○ | 注文数量 |
| 4 | plannedStartDate / plannedEndDate | date | ○ | 計画日程 |
| 5 | operations[] | array | ○ | 工序（seq・code・name・workCenterCode・setupTime・runTimePerUnit） |
| 6 | materials[] | array | ○ | 材料（code・requiredQty・uom・warehouseCode） |

**回传項目（MES → PRD）**

| No | 項目 | 型 | 必須 | 説明 |
|---|---|---|---|---|
| 1 | workOrderNo | string | ○ | 工单番号 |
| 2 | operationSeq | int | ○ | 工序 SEQ |
| 3 | reportAt | datetime | ○ | 完了日時（冪等キー） |
| 4 | goodQty / defectQty / scrapQty | string | ○ | 数量 |
| 5 | laborHours / machineHours | string | ○ | 工数 |
| 6 | operatorCode | string | △ | 作業者（工号） |
| 7 | defectCodes[] | array | △ | 缺陷コード・数量 |
| 8 | equipmentCode | string | △ | 設備 |

**異常時**：回传エラーは MES 側で再送。本域は冪等に処理し、`prd_work_report` を `report_status=20`（審核待ち）で登録する（自動確定はしない）。

### 6.2 IF-PRD-002 PLM BOM/工艺同步

| 項目 | 内容 |
|---|---|
| 方向 | PLM → PRD（受信） |
| データ | 品目・BOM（親子・数量・损耗率）・工艺路線（工序・WC・工時）・ECN 番号 |
| 頻度 | 日次バッチまたはイベント |
| 処理 | 受信データを `prd_bom`／`prd_routing` の**下書き（10）**として登録し、承認フローへ。直接有効化しない |
| 冪等 | `ecoNo + materialCode + versionNo` で重複排除 |
| 異常時 | 項目エラーはエラーファイルに出力し、担当者へ通知。部分取込はしない（全件成功 or 全件失敗） |
