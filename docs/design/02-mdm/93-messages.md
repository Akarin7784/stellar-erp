## 1. 採番・記述規則

| 項目 | 規則 |
|---|---|
| ID | `MSG-MDM-{3桁}`。域内連番。共通で表現できるものは `MSG-COM-xxx` を使用し、本表では重複定義しない |
| 種別 | `E`=エラー（処理中断）/ `W`=警告（続行可）/ `I`=情報・成功 / `C`=確認 |
| 本文 | 中文。利用者視点で「何が起きたか + どうすればよいか」。技術用語・例外名・スタックトレースを含めない |
| プレースホルダ | `{0}`、`{1}`… の順。例：`物料编码「{0}」` |
| 表示 | E=ダイアログ+項目赤字 / W=トースト（橙）/ I=トースト（緑）/ C=確認ダイアログ（[02 画面共通規格](../00-common/02-common-screen-spec.md) 第 13 章） |
| API コード | I/W（継続）は `code=0` + `message`。E は 20000〜29999 の業務コード（[91](91-api-design.md) 第 4 章） |
| 対処 | 利用者が次に取るべき行動を具体的に書く。「管理者に連絡」は最終手段として用いる |
